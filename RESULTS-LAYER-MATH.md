**Source of every number below: `results.json`**, which `collect_results.py`
merged from the per-arm run logs (`logs/<arm>.log`, written by `run_arm.py`)
and the gradient-check logs (`logs/gradcheck_<mode>.log`). This document was
generated by `gen_results.py` from that file; no number is typed from memory.

## Scope line (read first)

Same tiny teaching scale as reimplementation-01: d_model 128, 4 heads, 2+2 layers,
930,957 parameters (930,963 for QK-norm), synthetic reversal task, 20k/2k/2k seeded
splits, 10 epochs = 3,130 steps, pure NumPy on 2 CPU cores. These numbers say
something about *this* model on *this* task. They are not comparable to any
published benchmark, and no claim below reaches further than that.

by roughly 200s relative to the other arms. Per-epoch times are in the logs.

The baseline arm is a fresh re-run in this harness (same seed, same splits):
it scored 499/500 / 0/500 / 0/500,
against reimplementation-01's recorded 500/500, 0/500, 0/500. The two
out-of-distribution bands reproduce exactly; in-distribution differs by one
sequence (499 vs 500) and final val accuracy by 0.0008 (0.9992 vs 1.0000).

variant below is judged against this fresh baseline re-run in the same
harness, never against the recorded original.

## Baseline (fresh re-run in this harness)

The change: scores = QK^T / sqrt(dk); Adam (beta1 0.9, beta2 0.98); Noam warmup 200.

The control arm confirms the harness: final val token accuracy 0.9992, exact-match 499/500 in-distribution and 0/500 / 0/500 beyond the trained lengths. Length generalization is absent in the control, exactly as in reimplementation-01 — so any movement in the variant arms is attributable to the one change each arm makes, not to the fork.

 Gradient check (base math): PASS, worst relative error 4.91e-10 over 1633 elements.

## V1 — ALiBi-style distance penalty

The change: scores = QK^T / sqrt(dk) - m_h * |i - j|, per-head slopes m_h = 2^(-8h/H), subtracted before the softmax; no new parameters.

Nothing about the failure moves: 0/1000 out-of-distribution sequences decode exactly, statistically indistinguishable from the baseline's 0/1000. In-distribution performance is intact (val acc 0.9996, exact 495/500), so the change is neither harmful nor the missing ingredient at this scale — the length-generalization failure survives it untouched.

 Gradient check (alibi math): PASS, worst relative error 5.21e-10 over 1633 elements.

## V2 — QK-normalization (cosine attention)

The change: scores = tau * cos(Q, K): Q/K rows L2-normalized; tau is one learnable scalar per attention module (init sqrt(dk)), replacing 1/sqrt(dk); +6 parameters.

Nothing about the failure moves: 0/1000 out-of-distribution sequences decode exactly, statistically indistinguishable from the baseline's 0/1000. In-distribution performance is intact (val acc 1.0000, exact 500/500), so the change is neither harmful nor the missing ingredient at this scale — the length-generalization failure survives it untouched.

 Gradient check (qknorm math): PASS, worst relative error 5.43e-10 over 1636 elements.

## V3 — AdamW + longer warmup (optimizer arm)

The change: Baseline attention math; Adam -> AdamW (decoupled weight decay 0.1, uniform) and Noam warmup 200 -> 400 steps.

Nothing about the failure moves: 0/1000 out-of-distribution sequences decode exactly, statistically indistinguishable from the baseline's 0/1000. In-distribution performance is intact (val acc 1.0000, exact 500/500), so the change is neither harmful nor the missing ingredient at this scale — the length-generalization failure survives it untouched.

 Gradient check (base math): PASS, worst relative error 4.91e-10 over 1633 elements. (optimizer arm: attention math identical to baseline arm, covered by the baseline (base) gradient check.)

## What this does and does not show

It shows which of three specific, single-variable math changes — a distance
penalty in the attention scores, cosine attention with a learned temperature,
and an optimizer/schedule change — move one measured failure (length
generalization of a tiny from-scratch Transformer on sequence reversal), with
every arm's gradients verified numerically first. It does not show that the
winning (or losing) change behaves the same at real model scale, on real
language data, or in architectures with different positional schemes; each arm
changed exactly one variable, so combinations (e.g. ALiBi + QK-norm) are
untested by design. One seed per arm: differences of a few sequences in 500
are within seed noise and are not claimed as effects.
